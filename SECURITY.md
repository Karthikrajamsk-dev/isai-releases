# Security

- Only download Isai from this repository's **Releases** page.
- Each release lists the APK's SHA-256 and the signing certificate SHA-256. Isai's in-app updater refuses an update
  whose checksum or signing key doesn't match.
- Updates are fetched over HTTPS from GitHub only.
- Signing certificate SHA-256: `f128937a08f0a5f6eab15fd13b4e64c732a5fe889799a423cb35a24df70abd1e`

Found a security problem? Please don't post details publicly – open an issue titled "Security contact" and you'll be
contacted privately.
